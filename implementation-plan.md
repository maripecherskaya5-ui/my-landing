# План разработки «Мария / цифровая мастерская»

ТЗ согласовано Марией 30 сентября 2026 года. Название и русский язык утверждены.

Актуальный документ: [подробный план реализации](docs/superpowers/plans/2026-09-30-maria-landing.md).

Шесть этапов: страница и локальный запуск → оформление и мобильная версия → меню и демонстрация → форма → итоговая проверка → подготовка к публикации.

Рекомендуется реализация в текущем чате с отдельной итоговой проверкой другим агентом. План ожидает проверки Марии и выбора способа выполнения. Код ещё не создан.

Первая версия использует демонстрационные концепты. До настройки доставки форма работает без отправки и явно сообщает об этом. Для публичного запуска нужны рабочий контакт и настройка приёма обращений.
